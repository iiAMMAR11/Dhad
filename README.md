# ضاد | Dhad

مهارة وايت ليبل تحسّن تجربة المستخدم في المنتجات والتصاميم والعروض والمواقع وSaaS والتطبيقات والمستندات، وتمنح العربية وRTL عناية كاملة من دون فرض هوية بصرية أو تقنية.

[موقع الاستعراض](https://dhad.iiammar.com) · [English](README.en.md) · [الترخيص](LICENSE)

## ما الذي تضيفه؟

- أساس UX عام يحافظ على هوية المشروع.
- عربية صحيحة: اتجاه، جمع، ترتيب، بحث، أرقام، هجري، وقواعد المنطقة.
- أنماط للكيانات والبحث والمحتوى والبيانات الحية والانتقال بين الأجهزة.
- مهايئات للويب والتطبيقات والعروض والمستندات.
- تدقيق RTL وحزمة مطابقة وبوابة استقرار قبل الاعتماد.

## الاستخدام

```text
$dhad راجع هذا المشروع، حسّن التجربة، واجعل العربية وRTL جزءًا أصيلًا منه.
```

ابنِ حزم التثبيت من المصدر:

```bash
python3 scripts/build_releases.py
python3 scripts/verify_public_release.py
```

يمكن تثبيته مباشرة في Codex من هذا المستودع، أو استخدام الحزم الناتجة مع ChatGPT وCodex وClaude.

## الملكية والشكر

صاحب ضاد ومطوّرها **عمَّار**. ضاد عمل مستقل طُوّر على مدى أسابيع من الدراسة والتجريب والتدريب والتحسين.

شكرًا لمرصاد، وثمانية، ورياضة ثمانية، وللمهارات والمنتجات العربية التي وسّعت زاوية الدراسة. هذا شكر اختياري لا يعني نقلًا أو اشتقاقًا أو شراكة أو ملكية مشتركة في ضاد.

يضم المستودع خط IBM Plex Sans Arabic كخيار محلي مفتوح تحت OFL-1.1، وليس كخط إلزامي. المشروع المضيف يختار خطه وهويته.
