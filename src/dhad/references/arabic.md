# العربية والمنطقة

اقرأ هذا الملف عند وجود نص أو بيانات أو جمهور عربي.

## الاتجاه والنص المختلط

- اجعل الحاوية RTL عندما تكون العربية هي اللغة الأساسية.
- استخدم `bdi dir="auto"` للأسماء والعناوين التي يكتبها المستخدم.
- اجعل الرابط والبريد والكود والمسار والمعرّف والوقت والقيمة المالية الكاملة جزر LTR محلية.
- لا تقطع ناتج `Intl` أو تحذف علاماته الاتجاهية. استخدم `formatToParts` عند إعادة التركيب.
- في النص الصرف استخدم Unicode isolates حول القيمة المخالفة للاتجاه.

## راحة القراءة

- اترك فراغًا واضحًا بين بداية النص ونهاية الإطار من اليمين واليسار، بحسب اتجاه اللغة.
- لا تجعل السطور العربية تتلامس. استخدم ارتفاع سطر يتحمل الفتحة والضمة والكسرة والشدة والتنوين.
- اختبر عبارة مشكّلة فعلًا، لا تفترض أن النص غير المشكّل يكفي.
- إذا تزاحم عنوان كبير، قلّل حجمه أو عدد كلماته. لا تعالج الازدحام بضغط السطور.

## الجمع والترتيب

العربية لها ست فئات: `zero`, `one`, `two`, `few`, `many`, `other`. استخدم `Intl.PluralRules("ar")` ولا تختصرها إلى مفرد وجمع.

```js
const plural = new Intl.PluralRules("ar");
const forms = { zero: "لا توجد ملفات", one: "ملف واحد", two: "ملفان",
  few: "# ملفات", many: "# ملفًا", other: "# ملف" };
```

استخدم `Intl.Collator("ar", { numeric: true, sensitivity: "base" })` لكل ترتيب ظاهر. لا تستخدم `.sort()` الافتراضي للأسماء العربية.

## البحث وحفظ الأسماء

احتفظ بثلاث قيم منفصلة حتى لا تدمج شخصين أو ملفين بالخطأ:

- الأصل للعرض.
- فهرس بحث موسّع للمطابقة المتسامحة.
- معرّف ثابت للمساواة والدمج.

```js
const normalizeArabicSearch = (value) => value
  .normalize("NFKC")
  .replace(/[\u064B-\u065F\u0670\u0640]/g, "")
  .replace(/[إأآٱ]/g, "ا")
  .replace(/ى/g, "ي")
  .trim()
  .toLocaleLowerCase("ar");
```

مطابقة `ة` مع `ه` توسعة بحث اختيارية حسب المجال، وليست قاعدة للمساواة. لا تدمج سجلين لأن فهرس البحث متطابق؛ استخدم معرّفًا أو حقلًا موثوقًا.

## الأرقام والمال

- اختر نظام الأرقام صراحة: `ar-SA-u-nu-arab` أو `ar-SA-u-nu-latn`، وثبّته داخل الدور نفسه.
- اقبل الأرقام العربية واللاتينية في الإدخال، ثم حوّلها قبل التحقق.
- اجعل الهاتف والـIBAN والمعرّفات التقنية لاتينية وLTR.
- نسّق المال عند العرض، واحترم المنازل العشرية للعملة.
- اعزل رمز العملة والمبلغ والإشارة وعلامة التقريب معًا.
- ميّز بين صفر، قيمة مفقودة، تحويل معلّق، وسعر قديم.

## التاريخ والمنطقة

- خزّن ISO/Unix، واعرض التقويم المناسب. الهجري إسقاط عرض وليس صيغة تخزين.
- في السعودية استخدم `islamic-umalqura` عندما يكون أم القرى مطلوبًا.
- لا تحسب موعدًا تعاقديًا بجمع أيام هجرية مستقبلية؛ اعرضه من التاريخ الميلادي المخزّن.
- استخرج بداية الأسبوع والعطلة من المنطقة، ولا تفترض السبت والأحد.
- استخدم `Intl.DateTimeFormat` و`Intl.RelativeTimeFormat` بدل تركيب أسماء الأيام والأشهر يدويًا.
- لا تثبّت رمضان أو العيد على تاريخ ميلادي دائم.

## المحتوى

- اكتب فعلًا مباشرًا: «حفظ»، «نشر»، «إعادة المحاولة».
- صف النتيجة والإصلاح، لا الخطأ التقني: «تعذّر الحفظ. أعد المحاولة».
- لا تستخدم «موافق» لفعل مدمّر، ولا placeholder بدل label.
- اربط المساعدة والخطأ بالحقل عبر `aria-describedby`.
- الإيموجي اختيار دلالي يتبع هوية المنتج؛ لا تخلطه مع أنظمة أيقونات أخرى بلا أدوار واضحة.

## تحقق سريع

- جرّب الأعداد 0 و1 و2 و5 و11 و100 و103.
- جرّب آ/أ/إ/ا، واسمًا عربيًا وآخر لاتينيًا في الصف نفسه.
- جرّب بحث «احمد» عن «أحمد» من دون استخدام التطبيع للدمج.
- جرّب نصًا أطول 200%، وقيمة مالية سالبة، ورابطًا، وتاريخين ميلاديًا وهجريًا.
