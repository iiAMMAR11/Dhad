# ضاد

ضاد مهارة وايت ليبل تحسّن تجربة أي منتج أو مخرج، وتجعل العربية وRTL مواطنين من الدرجة الأولى من دون فرض هوية بصرية أو تقنية أو مجال عمل.

## طريقة العمل

1. افهم المهمة والجمهور والمخرج وهوية المشروع الحالية قبل اقتراح الشكل.
2. حافظ على قرارات المستخدم وعلامته ومكوّناته؛ لا تستبدل أساسًا صالحًا.
3. حمّل فقط ما تحتاجه:
   - أي تجربة أو واجهة: [الأساس](references/foundation.md).
   - نص أو بيانات عربية: [العربية والمنطقة](references/arabic.md).
   - موقع أو تطبيق أو عرض أو مستند: [المخرجات](references/outputs.md).
   - بحث أو محتوى أو كيانات أو تدفقات متقدمة: [الأنماط](references/patterns.md).
   - مراجعة أو تسليم أو اعتماد: [الجودة](references/quality.md).
4. نفّذ أقل طبقة تحقق الهدف، ثم اختبرها في سياقها الحقيقي.

## ثوابت ضاد

- اختيار المستخدم وهوية المشروع وعرف المنصة تتقدم على أي قيمة ابتدائية.
- لا تفرض خطًا أو لونًا أو وضعًا أو نصف قطر أو مكتبة. الأصول المرفقة نقطة بداية اختيارية.
- استخدم خصائص الاتجاه المنطقية، واعزل فقط القيم التي تحتاج LTR.
- افصل الاختيار عن النجاح، والحالة عن اللون، والبحث التقريبي عن هوية السجل.
- اجعل المحتوى ظاهرًا افتراضيًا، والتحكمات عاملة، والتركيز واضحًا، واللمس 44px على الأقل أو عرف المنصة إن كان أكبر.
- اختبر النص العربي الطويل، الاتجاه المختلط، لوحة المفاتيح، قارئ الشاشة، التكبير، الهاتف، والحركة المخفّضة.
- لا تنقل مفردات أو شكل أو منطق مجال إلى مشروع آخر بلا سبب من متطلبات المشروع.
- تبقى مراجع الدراسة خارج ملفات المهارة التشغيلية؛ مكان الشكر العام هو README وموقع الاستعراض فقط.

## التسليم

اذكر باختصار ما طُبّق، وما بقي اقتراحًا، والاتجاه والأرقام والتاريخ والمنصات والحالات التي تحققت منها.
