# سياسة النشر العام

## Release 1 فقط

لا تُنشر نسخ مراجعة أو حزم تجريبية في صفحة Releases العامة. بعد اكتمال العمل واعتماد المعرض والنتيجة بصريًا، يُنشر **Release 1** بوصفه أول إصدار عام.

## مصدر واحد وحزمتا تثبيت

يحتوي Release 1 على حزمتين مبنيتين من المصدر نفسه:

1. `Dhad-openai-plugin.zip`: حزمة OpenAI Plugin لـChatGPT وCodex، وبداخلها السكيل المستقل لتثبيت Codex المحلي وامتداد IDE.
2. `Dhad-agent-skill.zip`: حزمة Agent Skill للرفع إلى Claude Chat أو النسخ إلى Claude Code، من دون `.claude-plugin`.

هذه ليست نسختين من نظام التصميم. الحزمتان غلافا تثبيت حول المصدر نفسه، ويجب أن تتطابق ملفات السكيل والمراجع والأصول المشتركة داخلهما. تحتوي كل حزمة على `INSTALL.md` خاص بقنواتها.

## بوابة الاعتماد

قبل نشر Release 1:

- يعتمد المالك المعرض والشكل النهائي صراحة.
- تتطابق التوكنز والمكوّنات المعروضة مع الحزمة العامة.
- تنجح اختبارات contrast وkeyboard وRTL والاستجابة والحزم.
- لا توجد ملفات خطوط غير IBM Plex Sans Arabic المضمّن تحت OFL-1.1، ولا مفاتيح أو أسرار أو بيانات مستخدمين.
- تُسمى مستويات النضج بصدق: stable أو beta أو recipe أو experimental.
- تُحذف أي مواد مراجعة عامة لا تنتمي إلى الإصدار المعتمد.

## سير الإصدار

1. ثبّت الاسم والبيانات العامة وبيان Plugin.
2. شغّل `python3 scripts/build_releases.py`.
3. شغّل `python3 scripts/verify_public_release.py`.
4. اختبر طلبات تشغيل مباشرة وغير مباشرة على المنصات المستهدفة.
5. اعرض المعرض والحزم النهائية على المالك للاعتماد.
6. أنشئ Tag الإصدار العام وانشر Release 1 مع الحزمتين و`SHA256SUMS.txt` فقط.

## قاعدة قانونية ثابتة

يسمح التحقق فقط بملفات WOFF2 الثمانية المحددة لـIBM Plex Sans Arabic داخل مسار الخطوط الرسمي، ويفشل عند وجود أي خط آخر أو ملف خط في مسار مختلف. ويفشل أيضًا إذا احتوت حزمة Agent Skill على `.claude-plugin`، أو خالفت أي حزمة مسار `SKILL.md` أو بيانها المطلوب.
