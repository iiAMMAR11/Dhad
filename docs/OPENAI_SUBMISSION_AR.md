# تجهيز نشر Plugin في دليل ChatGPT وCodex

## نوع الإرسال

اختر `Skills only`. لا يحتاج Dhad إلى MCP أو تسجيل دخول أو بيانات اعتماد.

ملف الإرسال هو `Dhad-openai-plugin.zip`. وهو حزمة OpenAI المشتركة لـChatGPT وCodex، وبنيته المطلوبة:

```text
dhad/
├── .codex-plugin/plugin.json
├── skills/dhad/SKILL.md
├── INSTALL.md
├── LICENSE
├── NOTICE.md
├── PRIVACY.md
├── TERMS.md
└── SUPPORT.md
```

## بيانات القائمة

- الاسم: `Dhad`
- الفئة: `Developer Tools`
- الناشر: `Ammar`
- الوصف القصير: `تصميم وصحّة عربية RTL للمنتجات الرقمية.`
- الوصف الطويل: `يصمّم Dhad واجهات عربية RTL متكيّفة مع هوية المنتج، ويضبط الجمع والترتيب والبحث والأرقام والتواريخ والتقويم الهجري. خرائط المنصات الأصلية نقاط بداية وليست مكتبات مكوّنات كاملة.`
- الموقع: `https://dhad.iiammar.com`
- الدعم: `https://github.com/iiAMMAR11/Dhad/blob/main/SUPPORT.md`
- الخصوصية: `https://github.com/iiAMMAR11/Dhad/blob/main/PRIVACY.md`
- الشروط: `https://github.com/iiAMMAR11/Dhad/blob/main/TERMS.md`

## Starter prompts

1. `طبّق Dhad على لوحة SaaS العربية في هذا المشروع.`
2. `حوّل هذه الواجهة إلى RTL كامل مع الوضعين الداكن والفاتح.`
3. `ابنِ شاشة جوال عربية باستخدام توكنز Dhad ومكوّنات المنصة الأصلية.`
4. `راجع هذه الواجهة وحدد مخالفاتها لـDhad ثم أصلحها.`
5. `استخدم إيموجي متناسقة مع هذا المنتج، ولا تضفها إذا لم تنتمِ لهويته.`

## حالات الاختبار الإيجابية

1. طلب تصميم Dashboard عربي جديد: يقرأ core وplatforms، ينشئ توكنز ومكونات RTL ويختبر الحالات.
2. طلب تحويل واجهة React قائمة: يحافظ على البنية العاملة ويطبّق النظام تدريجيًا.
3. طلب شاشة React Native: يستخدم خريطة المنصة ولا ينسخ CSS حرفيًا.
4. طلب دعم light/dark: يحافظ على الأدوار الدلالية ويختبر التباين.
5. طلب خط عربي: يستخدم IBM Plex Sans Arabic المضمّن ولا يضيف عائلة عربية ثانية.
6. طلب إيموجي: يبني قاموسًا خاصًا بمجال المنتج ويضيف أسماء متاحة للأزرار الرمزية.

## حالات الاختبار السلبية

1. `أضف خطًا عربيًا ثانيًا`: لا يخلط عائلتين عربيتين داخل نظام Dhad.
2. `انسخ منطق Firebase كاملًا من مشروع آخر`: يرفض اعتباره جزءًا من التصميم ويطلب نطاقًا برمجيًا مستقلًا.
3. `استخدم النظام لتحرير عرض PowerPoint`: لا يفعّل الـSkill تلقائيًا لأنه خاص بواجهات المنتجات الرقمية.
4. منتج يعتمد أيقونات أصلية ولا يطلب إيموجي: لا يفرض السكيل إيموجي عليه.

## قبل الإرسال

- وثّق هوية فرد أو شركة في OpenAI Platform.
- تأكد أن للحساب صلاحية Apps Management: Write.
- انشر المستودع وروابط الموقع والدعم والخصوصية والشروط.
- بعد الاعتماد البصري، ارفع `Dhad-openai-plugin.zip` من Release 1 واستخدم مواد الاختبار أعلاه.
- طابق قيمة `version` في `.codex-plugin/plugin.json` مع `VERSION`، وتأكد أن `skills` يشير إلى `./skills/`.
- شغّل `python3 scripts/verify_public_release.py` وتحقق من `SHA256SUMS.txt` قبل الرفع.
- أرسل للمراجعة. الموافقة لا تنشره تلقائيًا؛ بعد الموافقة اختر Publish من البوابة.
