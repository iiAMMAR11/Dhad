# اعتماد النظام في المنتجات

## نطاق التطبيق

يتكون Dhad من ثلاث طبقات:

1. **النواة**: الألوان، الخطوط، المسافات، الحركة، الحواف، الحالات، الحقول والأزرار.
2. **أنماط المنتج**: التنقل، القوائم، اللوحات، الحفظ والمزامنة، البحث، الحالات الفارغة والـsheets.
3. **وصفات المجال**: مكوّنات مرتبطة بسياق محدد مثل المشاهد والتايم كود. لا تنتقل إلى منتج آخر إلا إذا كان معناها حقيقيًا فيه.

ابدأ كذلك بقرار صريح حول المفردات البصرية: هل طلب المستخدم إيموجي؟ هل يستعملها المنتج أصلًا؟ إذا لم تنتمِ إلى اللغة القائمة فلا تضفها. عند استخدامها، ابنِ قاموسًا خاصًا بالمجال وفق [سياسة الإيموجي](EMOJI_AR.md).

## موقع أو صفحة تسويقية

- استخدم النواة الطباعية واللونية والإيقاع العربي.
- اجعل RTL هو الاتجاه الأساسي، مع LTR محلي للروابط والأكواد.
- لا تنقل مكوّنات لوحة الإنتاج لمجرد أنها موجودة في الكتالوج.
- حافظ على هدف واضح لكل عنصر تفاعلي وعلى تسلسل لوحة المفاتيح.

## SaaS أو لوحة تحكم

- ابدأ بالتوكنز، الحقول، الأزرار، حالات الحفظ، الإشعارات، الجداول أو اللوحات.
- أظهر حالة الاتصال والمزامنة عندما تؤثر على موثوقية البيانات.
- حوّل حالات المجال إلى أدوار دلالية بدل تثبيت أسماء مراحل منتج بعينه.
- اختبر البيانات الطويلة، القيم الفارغة، الأخطاء والصلاحيات المختلفة.

## تطبيق جوال

- استخدم مكوّنات المنصة الأصلية مع ألوان وإيقاع Dhad.
- الحد الأدنى للمس 44×44 نقطة منطقية، أو معيار المنصة إذا كان أكبر.
- احترم safe areas ولوحة المفاتيح وتكبير الخط وحركة النظام المخفّضة.
- لا تنسخ CSS إلى React Native أو Flutter حرفيًا؛ طبّق الأدوار داخل نظام الثيم الأصلي.

## تطبيق سطح مكتب

- أضف تنقل لوحة المفاتيح، focus واضحًا، اختصارات مناسبة وأحجام نوافذ قابلة للتغيير.
- اجعل الكثافة أعلى قليلًا من الجوال من دون تقليل قابلية القراءة.
- استخدم أنماط النظام للنوافذ والقوائم عندما تكون أوضح للمستخدم.

## منتج غير عربي

النظام مصمم للعربية وRTL. يمكن دعمه ثنائي الاتجاه، لكن لا تجعل LTR يغيّر معنى الألوان أو ترتيب سير العمل. اختبر كل لغة كتخطيط فعلي، لا كقلب بصري آلي.

## تعريف الاكتمال

لا يعد التطبيق مكتملًا حتى يعمل في الوضعين، RTL ومواضع LTR المحلية، الجوال وسطح المكتب، لوحة المفاتيح أو أدوات الوصول، النص الطويل، الحالات الفارغة، الخطأ، عدم الاتصال والحركة المخفّضة.

## لا تخلط مستويات النضج

- **Implemented**: أصل موجود ومختبر في الحزمة.
- **Recipe**: تركيب موثق يجب تنفيذه داخل بنية المشروع.
- **Theme starter**: خريطة قيم لمنصة أصلية، لا مكتبة مكوّنات.
- **Guidance only**: متطلبات تحتاج تنفيذًا واختبارًا كاملين في المنتج المضيف.

React Native وFlutter وSwiftUI وAndroid Compose في المستودع Theme starters. لا تستخدم عبارة «دعم كامل» لهذه المسارات حتى تصبح لها مكوّنات واختبارات مستقلة.
