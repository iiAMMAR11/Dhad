# الخط في ضاد

خط ضاد الوحيد هو **IBM Plex Sans Arabic** برخصة SIL Open Font License 1.1 — مضمّن مع السكِل بأوزانه الثمانية في `src/dhad/assets/starter/fonts/` ويعمل بلا اتصال ولا CDN ولا أي فحص ترخيص.

## الأوزان وأدوارها

| الوزن | الدور |
|---|---|
| 100 / 200 | أرقام وعناوين عرض ضخمة (≥40px) فقط |
| 300 | عناوين فرعية هادئة فوق 28px فقط |
| 400 | النص الثانوي والوصف والتلميحات |
| **450 (Text)** | **النص الجاري — الافتراضي** |
| 500 | الأزرار والتسميات والحقول والأرقام المالية |
| 600 | عناوين الأقسام والبطاقات والحوارات |
| 700 | عنوان الصفحة والهوية والأرقام المفتاحية |

## قواعد التسلسل الهرمي

- المستويات المتجاورة تختلف في قناتين على الأقل من: الوزن، الحجم، اللون.
- التخفيف بالّلون الخافت لا بالأوزان تحت 400 — الخفيف بالأحجام الصغيرة غير مقروء عربيًا.
- المقاسات نسبية لمشروعك: أساس مريح للنص 17–18px ويتدرّج الباقي منه، والمنتجات الكثيفة تنزل الأساس درجة.
- `letter-spacing: 0` دائمًا، وارتفاع السطر للنص الجاري ≥ 1.7.

## الاستخدام

- الويب: `dhad.fonts.css` + مجلد `fonts/` كما هما (مستوردان في `dhad.core.css` مسبقًا).
- npm: `npm i @ibm/plex-sans-arabic` واستورد CSS الحزمة.
- Native: ضمّن ملفات woff2/ttf وسجّل العائلة حسب المنصة، مع إبقاء `OFL-LICENSE.txt`.

التفاصيل الكاملة في `src/dhad/references/fonts.md`.
