# Privacy Policy

Effective date: 2026-08-26

Dhad is a skills-only design-system package. It does not operate a server, request authentication, create user accounts, collect analytics, or transmit personal data to the publisher.

When the skill is used, the host product may process prompts, project files, and generated output according to that product's own privacy policy and the user's workspace settings. The Dhad package itself does not add network tools or external data connections.

The package contains static instructions, design tokens, documentation, starter source files, and the IBM Plex Sans Arabic font files (OFL-1.1).

Questions may be sent to the support address listed in [SUPPORT.md](SUPPORT.md).
